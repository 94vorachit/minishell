## Suggested implementation order

### 1. Add command data structures

Extend `includes/minishell.h` with structures for:

```c
t_token
t_command
```

For example, a command should eventually contain:

```text
argv
input redirection
output redirection
append redirection
heredoc delimiter
next command in pipeline
```

### 2. Implement the lexer/tokenizer

Create files such as:

```text
src/lexer.c
src/token_utils.c
```

Support initially:

```bash
word
"quoted text"
'single quoted text'
|
<
>
>>
<<
```

The lexer must preserve quote information so expansion can be handled correctly later.

### 3. Implement syntax validation

Reject invalid input such as:

```bash
|
ls |
ls >
echo "unfinished
```

Set the exit status to `258` for syntax errors, matching Bash and the constant already defined in the header.

### 4. Implement simple command execution

For a command without pipes or redirections:

```text
if command is builtin:
    execute builtin directly
else:
    fork()
    child: execve()
    parent: waitpid()
```

Use `PATH` to find commands such as `ls`, `cat`, and `grep`.

### 5. Implement mandatory builtins

Implement these one by one:

```text
echo
cd
pwd
export
unset
env
exit
```

Recommended order:

1. `echo`
2. `pwd`
3. `env`
4. `export`
5. `unset`
6. `cd`
7. `exit`

The existing `t_env` list can be reused, but you will need helpers for:

```text
find environment variable
set/update variable
remove variable
convert linked list to char **
free environment list
```

### 6. Add redirections and pipes

After simple commands work:

```bash
echo hello > file
cat < file
echo hello >> file
cat << EOF
hello
EOF
```

Then pipelines:

```bash
ls | grep .c
cat file | sort | wc -l
```

### 7. Fix the current loop issues

In `src/main.c`, the current loop should eventually:

- call `add_history(line)` for non-empty input
- free `line`
- process `Ctrl+D` cleanly
- update `g_data->status`
- free all allocated command structures
- free the environment before exiting

Also, `sig_interrupt()` currently calls `exit(1)`, which would terminate the entire shell during heredoc handling. It should only terminate the heredoc child process, not the interactive parent shell.
