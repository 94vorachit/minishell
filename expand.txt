### Supported behavior

```bash
echo $USER
echo "$USER"
echo '$USER'
echo hello$USER
echo "$HOME/bin"
echo $?
echo '$?'
echo $UNDEFINED
```

Expected behavior:

```text
$USER       -> environment value
"$USER"     -> environment value
'$USER'     -> literal $USER
$UNDEFINED  -> empty string
$?          -> previous exit status
'$?'        -> literal $?
```
