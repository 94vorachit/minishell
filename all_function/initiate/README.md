`initiate_values` initializes the shell’s global runtime state before the main command loop starts.

```c
void initiate_values(t_data *g_data, char **env)
```

- `g_data`: pointer to the shell’s main state structure.
- `env`: environment variables received from `main`, usually the system’s `environ` array.

### Step by step

```c
g_data->lastret = 0;
```

Initializes the last command’s exit status to `0`, meaning success.

This value is later used for `$?`.

```c
g_data->env = env;
```

Stores the environment passed by the operating system in `g_data->env`.

```c
g_data->env = array_dup();
```

Replaces that pointer with a duplicated copy of the environment.

`array_dup()` uses the global `g_data->env` to copy each environment string. This gives the shell its own modifiable environment, so built-ins such as `export`, `unset`, and `cd` can change it without modifying the original `env` array.

The two assignments together are intentional: the first provides the source environment, and the second creates the independent copy.

```c
g_data->hd = 0;
```

Initializes the here-document pointer/state to `NULL` or zero.

Here-documents are used with syntax such as:

```bash
cat << EOF
text
EOF
```

```c
shlvlhandler(NULL, NULL);
```

Updates shell-related environment variables:

- Increments `SHLVL`.
- Sets `_` to `/usr/bin/env`.
- Resets or creates `OLDPWD`.
- Handles unusually large shell levels.

`shlvlhandler` modifies `g_data->env` through the global `g_data` pointer.

```c
tcgetattr(0, &g_data->old);
tcgetattr(0, &g_data->new);
```

Reads the current terminal settings for standard input (`file descriptor 0`) and stores them in `old` and `new`.

- `old` keeps the original terminal configuration.
- `new` is the copy that will be modified.

```c
g_data->new.c_lflag &= ~(ECHOCTL);
```

Disables `ECHOCTL`.

Normally, pressing `Ctrl-C` or `Ctrl-\` may display control characters such as:

```text
^C
^\
```

This prevents the terminal from automatically echoing those characters. The shell’s own signal handlers control how they are displayed.

```c
tcsetattr(0, TCSANOW, &g_data->new);
```

Applies the modified terminal settings immediately.

- `0`: standard input.
- `TCSANOW`: apply the changes now.
- `&g_data->new`: the new terminal configuration.

```c
signal(SIGINT, c_handler);
```

Installs `c_handler` for `SIGINT`, usually generated by pressing `Ctrl-C`.

The handler clears the current readline input and displays a fresh prompt instead of terminating the shell.

```c
signal(SIGQUIT, SIG_IGN);
```

Ignores `SIGQUIT`, usually generated by pressing `Ctrl-\`.

This prevents the interactive shell itself from quitting or producing a core dump when `Ctrl-\` is pressed.

### Overall purpose

The function prepares:

1. The shell’s exit-status state.
2. A private, editable copy of the environment.
3. Here-document state.
4. `SHLVL` and related environment variables.
5. Terminal behavior.
6. Interactive signal handling.

It is called once in `main` before `main_2()` starts the command-reading loop.
