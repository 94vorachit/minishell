## Step 2: simple command execution

The shell is already at the right place: main.c validates syntax and expands tokens, but it still does not actually run anything. The next step is to turn the expanded token list into one simple command and execute it.

### 1) Add a minimal command structure
Add this to minishell.h:

```c
typedef struct s_cmd
{
	char	**argv;
	char	*infile;
	char	*outfile;
	int		append;
	int		heredoc;
}	t_cmd;
```

You do not need full pipeline support yet. For now, a command is just:

- `argv` for arguments
- optional `infile`
- optional `outfile`
- `append` flag for `>>`

---

### 2) Build one command from tokens
After syntax validation and variable expansion, create a function like:

```c
int build_simple_cmd(t_token *tokens, t_cmd *cmd)
{
	// 1. collect words into argv
	// 2. stop at pipe or redirection
	// 3. if token is < or >, read following word as file
	// 4. end argv with NULL
}
```

Example flow:

```c
t_token *cur = tokens;
int argc = 0;

while (cur && cur->type != T_PIPE)
{
	if (cur->type == T_WORD)
	{
		argc++;
		cur = cur->next;
	}
	else if (cur->type == T_REDIR_IN && cur->next && cur->next->type == T_WORD)
	{
		cmd->infile = ft_strdup(cur->next->value);
		cur = cur->next->next;
	}
	else if ((cur->type == T_REDIR_OUT || cur->type == T_APPEND)
		&& cur->next && cur->next->type == T_WORD)
	{
		cmd->outfile = ft_strdup(cur->next->value);
		cmd->append = (cur->type == T_APPEND);
		cur = cur->next->next;
	}
	else
		return (-1);
}
```

Then allocate:

```c
cmd->argv = malloc(sizeof(char *) * (argc + 1));
cmd->argv[argc] = NULL;
```

This is the core of the parser for now.

```c
int execute_simple_cmd(t_data *data, t_cmd *cmd)
{
	pid_t	pid;
	int		status;

	if (!cmd || !cmd->argv || !cmd->argv[0])
		return (SUCCESS);

	// builtins later: echo, pwd, env, exit...
	// for now, handle external command only

	if (pid == 0)
	{
		// child: set redirections if needed
		// execve

	waitpid(pid, &status, 0);
	data->status = WEXITSTATUS(status);
	return (SUCCESS);
```

### 6) Very important rule
Do not try to do pipes or heredoc yet. Keep it to:

- 1 command
- no `|`
- no `<<`
- no `>>` except optional simple outfile handling
